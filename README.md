# dain의 할 일 목록

로그인 없이 함께 쓰는 할 일 목록 웹앱이에요.

## 바로 써 보기

👉 https://todo-dain.vercel.app

## 할 수 있는 일

- 할 일 추가, 체크(완료 표시), 지우기
- 작성자 이름 붙이기 (안 적어도 돼요)
- 마감일 붙이기 (안 골라도 돼요)
  - 마감이 가까운 순서로 보이고, 마감일 없는 할 일은 아래쪽에 보여요.
  - 오늘이 마감이면 주황색, 마감이 지났으면 빨간색으로 보여요.
- 할 일 글자를 두 번 눌러서 고치기 (Enter는 저장, Esc는 취소)
- 전체 · 진행 중 · 완료 골라 보기, 남은 할 일 개수 보기
- 한글을 입력하다가 Enter를 눌러도 두 번 처리되지 않아요.

## 사용한 기술

- **HTML · CSS · JavaScript**: 빌드 도구 없이 순수하게 만들었어요.
- **[Supabase](https://supabase.com)**: 할 일을 저장하는 데이터베이스예요.
- **[Vercel](https://vercel.com)**: 사이트를 배포해요. GitHub에 푸시하면 자동으로 다시 배포돼요.

## 내 컴퓨터에서 실행하기

`index.html`을 더블클릭하면 브라우저에서 열려요.
Supabase에서 할 일을 불러오기 때문에 인터넷에 연결되어 있어야 해요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면의 뼈대 (입력 칸, 버튼, 목록) |
| `style.css` | 화면 꾸미기 (색, 크기, 배치) |
| `script.js` | 동작 (추가 · 고치기 · 지우기 · 골라 보기, Supabase와 주고받기) |
| `config.js` | Supabase 주소와 공개용 열쇠(publishable key) |

## 데이터베이스

Supabase의 `todos` 표 한 줄이 할 일 하나예요.

| 열 | 뜻 |
|---|---|
| `id` | 할 일 번호 |
| `title` | 할 일 내용 |
| `author` | 작성자 이름 (없으면 비어 있음) |
| `due_date` | 마감일 (없으면 비어 있음) |
| `is_done` | 완료했는지 |
| `created_at` | 만든 시각 |

### 보안

- `todos` 표에는 RLS(행 수준 보안)가 켜져 있어요.
- 로그인 없는 공유 목록이라서, 누구나 읽기 · 추가 · 고치기 · 지우기를 할 수 있도록 **일부러** 허용했어요.
- `config.js`의 publishable key는 브라우저에 공개돼도 되는 열쇠예요. 비밀 열쇠(secret key)는 이 저장소에 넣지 않아요.
